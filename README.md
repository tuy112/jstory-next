# 디렉토리 세부 설명

- `app`<br />
  → URL 페이지 담당

- `features`<br />
  → 실제 화면 컴포넌트

- `components`<br />
  → 공통 / 재사용 컴포넌트

- `styles`<br />
  → 전역 CSS, 변수, reset, utility 관리

- `public`<br />
  → 이미지 및 정적 리소스 관리

---

# CSS 구성

- `globals.css`<br />
  → reset.css + tokens.css + utilities.css import만 담당

- `tokens.css`<br />
  → 색상, 폰트, z-index, shadow, radius 등 공통 변수 정의

- `reset.css`<br />
  → 태그 초기화

- `utilities.css`<br />
  → hide, line, goTop 등 공통 유틸리티 클래스 관리

- `*.module.css`<br />
  → Header, Footer, Gate 등 컴포넌트별 스타일 관리
